## Documentação do projeto

# Atividade - Histórico do usuário

Nesta atividade eu alterei a tela do quiz para mostrar o histórico de pontuação do usuário.

O histórico aparece abaixo do quiz e mostra as pontuações que o usuário já fez.

## Arquivos alterados

- `quiz-app/frontend/src/App.jsx`
- `quiz-app/frontend/src/App.css`

## Como executar

Entre na pasta do frontend e rode:

```bash
npm install
npm run dev
```

Depois é só abrir o endereço que aparecer no terminal.

## O que foi feito

No `App.jsx` eu coloquei a parte que mostra o histórico do usuário.

No `App.css` eu adicionei o estilo do histórico para ele ficar organizado na tela.
